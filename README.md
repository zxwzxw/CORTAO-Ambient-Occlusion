# CORTAO Ambient Occlusion 1.2.1

Documentation for the CORTAO screen-space ambient occlusion plugin for Unreal Engine 5. This repository contains documentation only.

| Language | Guide |
| --- | --- |
| English | [Installation, configuration, Blueprint and troubleshooting guide](docs/tutorial-en.md) |
| 简体中文 | [安装、配置、蓝图及故障排查教程](docs/tutorial-zh-CN.md) |

The guides cover the Win64 packages prepared for **UE 5.6.1**, **UE 5.7.4**, and **UE 5.8.4**. Start by checking your exact engine build and renderer before installing.

本文档适用于为 **UE 5.6.1、5.7.4、5.8.4** 准备的 Win64 版本。安装前请先确认引擎构建版本及项目的渲染路径。
